## What is FED TTS?

FED TTS (Fluid Enhanced Dynamic Text-to-Speech) is a 100% offline, privacy-first transcription and text-to-speech application. It allows users to:

1. Upload audio files for manual transcription
2. Check spelling and grammar using deterministic (non-AI) methods
3. Read text aloud using the browser's native speech synthesis

## Key Principles

- **No AI/ML** – Only deterministic algorithms are used
- **Privacy First** – No data leaves your machine
- **100% Offline** – No cloud calls or external APIs
- **Open Source** – MIT licensed
