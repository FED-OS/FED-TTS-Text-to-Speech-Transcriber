# 🗺️ FED TTS Roadmap

## Version 0.1.0 (Current - Released)

### ✅ Completed
- [x] File upload (MP3, WAV, M4A, FLAC, OGG)
- [x] Manual transcription with text area
- [x] Dictionary-based spell checking
- [x] Regex-based grammar rules (would of, could of, should of, must of, double spaces, passive voice, long sentences)
- [x] Native browser TTS via SpeechSynthesis API
- [x] Stop speech button
- [x] Session state persistence
- [x] Custom CSS styling
- [x] Word and character count
- [x] Ko-fi support button
- [x] Complete documentation suite
- [x] GitHub Actions workflows (16 total)
- [x] Issue and PR templates
- [x] Docker support
- [x] Test suite with pytest
- [x] Pre-commit hooks

---

## Community Contributions

We welcome community contributions to help shape this roadmap! If you have an idea:

1. Check if it's already on the roadmap
2. Open a [feature request](https://github.com/your-github-username/fed-tts/issues/new/choose)
3. Discuss it in [GitHub Discussions](https://github.com/your-github-username/fed-tts/discussions)
4. Submit a PR if you'd like to implement it yourself

- 🐛 Bug fixes

- 🎨 UI/UX enhancements
