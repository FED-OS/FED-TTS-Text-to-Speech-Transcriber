# 📚 FED TTS - Citations and Attributions

## How to Cite FED TTS

If you use FED TTS in your research or publication, please cite it as follows:

### APA Format

[Your Name]. (2026). *FED TTS: Transcriber + Read Aloud* (Version 0.1.0) [Computer software]. GitHub. https://github.com/your-github-username/fed-tts

### MLA Format

[Your Name]. "FED TTS: Transcriber + Read Aloud." Version 0.1.0, GitHub, 2026, github.com/your-github-username/fed-tts.

### Chicago Format

[Your Name]. 2026. *FED TTS: Transcriber + Read Aloud*. Version 0.1.0. https://github.com/your-github-username/fed-tts.

### BibTeX

```bibtex
@software{YourName2026FED,
  author = {[Your Name]},
  title = {FED TTS: Transcriber + Read Aloud},
  year = {2026},
  version = {0.1.0},
  publisher = {GitHub},
  url = {https://github.com/your-github-username/fed-tts}
}
```

### RIS Format

```
TY  - COMP
AU  - [Your Name]
PY  - 2026
TI  - FED TTS: Transcriber + Read Aloud
PB  - GitHub
UR  - https://github.com/your-github-username/fed-tts
ER  - 
```
