## Data Collection

**FED TTS does not collect any data.** All processing happens locally on the user's machine. No data is sent to any server, cloud service, or third party.

## Privacy Policy

Your privacy is important to us. FED TTS:

- ✅ Does **not** collect any user data
- ✅ Does **not** send files to the cloud
- ✅ Does **not** use analytics or tracking
- ✅ Does **not** require internet access (except for the browser to run Streamlit)
- ✅ Does **not** use cookies
- ✅ Does **not** use AI or machine learning
- ✅ Does **not** make any external API calls

All data stays on your machine, always.

## Telemetry

FED TTS has **zero telemetry**. We do not collect:
- Usage statistics
- Error reports
- Crash data
- Device information
- IP addresses
- Any other data

Streamlit itself may collect anonymous usage stats by default, but this can be disabled in `.streamlit/config.toml`:

```toml
[browser]
gatherUsageStats = false
```

We recommend disabling this for maximum privacy.
